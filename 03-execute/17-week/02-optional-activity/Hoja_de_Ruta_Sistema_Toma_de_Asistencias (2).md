# Hoja de Ruta del Proyecto

## Sistema de Toma de Asistencias

### Objetivo

Planificar las fases del desarrollo del Sistema de Toma de Asistencias,
definiendo las actividades principales y los entregables de cada etapa
para garantizar una ejecución organizada del proyecto.

------------------------------------------------------------------------

## Fase 1. Análisis

**Objetivo:** Comprender la problemática actual y definir el alcance del
proyecto.

**Actividades principales:** - Analizar el proceso actual de toma de
asistencia. - Identificar los actores involucrados. - Definir el
problema, objetivos y alcance del sistema. - Identificar restricciones y
necesidades del proyecto.

**Entregable:** - Documento de análisis.

------------------------------------------------------------------------

## Fase 2. Levantamiento de Requerimientos

**Objetivo:** Identificar y documentar las necesidades del sistema.

**Actividades principales:** - Recopilar información mediante
entrevistas y observación. - Definir los requisitos funcionales. -
Definir los requisitos no funcionales. - Elaborar y validar el documento
SRS.

**Entregable:** - Documento SRS aprobado.

------------------------------------------------------------------------

## Fase 3. Diseño

**Objetivo:** Diseñar la estructura y funcionamiento del sistema.

**Actividades principales:** - Diseñar la arquitectura del sistema. -
Elaborar el modelo de base de datos. - Crear los diagramas UML. -
Diseñar la navegación y los mockups de la interfaz.

**Entregable:** - Diagramas UML. - Modelo de base de datos. - Mockups
del sistema.

------------------------------------------------------------------------

## Fase 4. Desarrollo

**Objetivo:** Construir el sistema de acuerdo con el diseño aprobado.

**Actividades principales:** - Configurar el entorno de desarrollo. -
Programar el backend. - Programar el frontend. - Integrar la base de
datos y los módulos del sistema.

**Entregable:** - Sistema funcional.

------------------------------------------------------------------------

## Fase 5. Pruebas

**Objetivo:** Verificar que el sistema funcione correctamente.

**Actividades principales:** - Ejecutar pruebas unitarias. - Realizar
pruebas de integración. - Ejecutar pruebas funcionales. - Corregir
errores encontrados.

**Entregable:** - Informe de pruebas. - Sistema validado.

------------------------------------------------------------------------

## Fase 6. Implementación

**Objetivo:** Poner el sistema en funcionamiento.

**Actividades principales:** - Configurar el ambiente de producción. -
Publicar el sistema. - Capacitar a los usuarios. - Verificar el correcto
funcionamiento.

**Entregable:** - Sistema implementado.

------------------------------------------------------------------------

## Fase 7. Mantenimiento

**Objetivo:** Garantizar el correcto funcionamiento y la mejora continua
del sistema.

**Actividades principales:** - Corregir errores. - Realizar
actualizaciones. - Ejecutar copias de seguridad. - Implementar mejoras
según las necesidades de los usuarios.

**Entregable:** - Plan de mantenimiento y mejoras.
