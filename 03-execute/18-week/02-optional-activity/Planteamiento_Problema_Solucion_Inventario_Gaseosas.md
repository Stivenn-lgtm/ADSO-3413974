EMPRESA DE GASEOSA 

## Problema 1: Control de productos vencidos

### Descripción del problema

La empresa presenta pérdidas debido a que no cuenta con un sistema que
controle las fechas de vencimiento de las gaseosas. El seguimiento se
realiza de forma manual, lo que puede ocasionar que algunos productos
permanezcan en el inventario después de su fecha de vencimiento,
afectando las ventas y la satisfacción de los clientes.

### Propuesta de solución

Desarrollar un sistema de gestión de inventario que registre la fecha de
vencimiento de cada lote de productos y genere alertas cuando una
gaseosa esté próxima a vencer. Además, el sistema permitirá consultar
reportes de los productos cercanos a su fecha de vencimiento para
facilitar su control y retiro oportuno.

## Problema 2: Desabastecimiento de productos

### Descripción del problema

La empresa no dispone de un control automatizado sobre las existencias
de las gaseosas. Esto provoca que algunos productos se agoten sin previo
aviso, ocasionando demoras en la reposición, pérdida de ventas y
dificultades para atender la demanda de los clientes.

### Propuesta de solución

Implementar un módulo de control de inventario que actualice
automáticamente las existencias cada vez que se registre una venta o una
entrada de mercancía. Cuando un producto alcance el nivel mínimo de
stock definido, el sistema enviará una alerta para realizar un nuevo
pedido al proveedor antes de que el producto se agote.
